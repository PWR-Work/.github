# PWR / WORK

### Open-source work system for power teams

People and AI collaborators working from shared context, within clear authority, toward measurable outcomes.

</div>

---

## Building in the open

PWR Work is for teams that need to turn research, decisions and execution into results they can understand and improve.

We are preparing the first public release. The initial focus is a trustworthy coordination foundation: clear project context, explicit human authority, evidence for decisions and measured outcomes.

## What we are working toward

- **Shared context** — the relevant decision, evidence and history are available where work happens.
- **Clear authority** — people and AI collaborators have named roles and visible boundaries.
- **Real outcomes** — teams can see what changed, what it cost and what to improve next.

## Current state

The canonical source repository is being prepared for its first public release. We will publish only workflows that can be reproduced from the tagged code and documentation.

The [W Method](https://w-method.nvgtrs.io/en/) and [W Manifesto](https://w-manifesto.nvgtrs.io/en/) describe the principles behind PWR Work.
